API Endpoints

GET /api/v1/status API status
GET /api/v1/auth/status Connection status
POST /ingest Ingest error logs
GET /api/v1/projects List projects
GET /api/v1/incidents List incidents
GET /api/v1/incidents/stats Incident statistics
GET /api/v1/settings/llm LLM configuration
GET /api/v1/usage/summary Usage statistics

Quick Start

Send an error to CRISPR:

curl -X POST http://localhost:8080/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "project": "owner/repo",
    "level": "ERROR",
    "message": "NullPointerException: Cannot read property",
    "stack_trace": "at UserService.getUser(UserService.java:42)"
  }'
